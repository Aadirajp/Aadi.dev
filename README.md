## 🌟 Overview

**Aadi.dev** is the personal portfolio and interactive engineering showcase of **Aditya Patil** — Computer Science & Artificial Intelligence student at **Newton School of Technology (ADYPU, Pune)**, software developer, and **Quantitative Research Consultant** at **WorldQuant BRAIN**.

Built from the ground up with modern semantic HTML5, custom vanilla CSS design tokens, and high-performance vanilla JavaScript (no heavy frameworks or bloated dependencies), the website embodies an **ultra-premium editorial cream aesthetic** reminiscent of high-end design houses, paired with real telemetry and genuine production assets.

## 🛠️ Local Development & Setup

This project uses zero external build tooling or bundlers, making it extraordinarily fast and easy to run locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aadirajp/Aadi.dev.git
   cd Aadi.dev
   ```

2. **Serve locally:**
   Using Python 3:
   ```bash
   python3 -m http.server 8000
   ```
   Or using Node.js `npx serve`:
   ```bash
   npx serve .
   ```

3. **Open in browser:**
   Navigate to [http://localhost:8000](http://localhost:8000)
